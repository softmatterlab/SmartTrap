# Bills of materials for the instrument controller

The boards are connected using two ribbon cable with 34-pin connectors.

With the two ... on them.
## Boards

###  Microcontroller board
Hosts the arduino portenta.

### Sensor board
Amplifies the signals from the various photosensors and hosts the analog digital converter used to sample these signals.

### Actuator board
Used to steer the motors of the instrument and to move the lasers.
